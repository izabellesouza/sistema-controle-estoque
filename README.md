# Sistema de Controle de Estoque

Projeto desenvolvido em Python utilizando o paradigma de Programação Procedural.

## Funcionalidades

- Cadastrar produto
- Listar produtos
- Buscar produto
- Entrada de estoque
- Saída de estoque
- Calcular valor total do estoque
- Mostrar estatísticas do estoque

## Dados do produto

Cada produto possui:

- Nome
- Preço
- Quantidade

## Regras implementadas

O sistema impede a retirada de uma quantidade maior do que a disponível em estoque.

Também foram implementados os desafios adicionais:

- Produto com maior quantidade
- Produto com menor quantidade
- Produto mais caro
- Produtos com estoque baixo

## Tecnologias

- Python
- PyCharm
